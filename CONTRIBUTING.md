# Contributing

Start with a small pull request explaining the proposed story or correction.

1. Use original text you have the right to submit. Do not supply private information
   about other people or claim fictional demo profiles are verified individuals.
2. Keep Spanish and English sentence meanings aligned. Preserve existing book,
   sentence and author IDs when correcting a published title.
3. Include the author's text profile and reference it by `authorID`.
4. Mark difficulty approximately; vocabulary alone does not establish CEFR level.
5. Run `npm test` and `npm run build`. Do not commit `dist/`.
6. Describe AI assistance, sources and the status of language/content review.

Maintainers check originality and permission, Spanish and English quality, suitable
content, author consent and metadata. Automated validation is not moderation.
A merged pull request is not automatically a published release. Unresolved content
licensing must be resolved before granting downstream reuse rights.

No author photo uploads are accepted. Portrait fields may refer only to supported
bundled demo assets or be empty; applications can render initials instead.
